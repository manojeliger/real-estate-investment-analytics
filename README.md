# Real Estate Investment & Property Analytics System

## Project Overview
This project uses PostgreSQL and SQL to analyze real-estate transactions, property prices, locality trends, and investment opportunities.

## Objectives
- Organize real-estate data in a relational database.
- Analyze property prices across different locations.
- Calculate price per square foot.
- Study property transaction trends over time.
- Calculate rental yield when rental data is available.
- Practise SQL queries and database optimization.

## Technology Stack
- PostgreSQL
- SQL
- Visual Studio Code
- Git and GitHub

## Project Structure
- `data/` — Dataset files
- `sql/` — SQL scripts
- `analysis/` — Analysis and findings
- `dashboard/` — Dashboard files and screenshots
